# 只是便签架构

本地保存直接写入，不看版本号。每条便签带一个待上传标记 `dirty` 和一个云端版本号 `serverVersion`。版本只在同步时核对。对不上就把另一版放进 `conflicts`，由人选择，不自动覆盖正文。

## 已确认

1. 正文继续用 TipTap JSON，另外存一份纯文本。
2. 文件夹冲突以云端为准，不弹窗。便签正文、置顶、所属文件夹只要版本对不上，都弹窗让人选。
3. 云端沿用现有表，另加迁移，不重建。
4. GitHub 另建 `just-note` 仓库，旧仓库归档。还没做。
5. 首版只导出，不做导入。导出有 JSON 备份，也有 Markdown、纯文本、网页文件。
6. 安卓应用 ID 为 `com.justnote`。桌面显示名是「只是便签」/ Just Note，不是这个 ID。

## 界面来源

界面和交互取自旧项目已发布版本 b251e3b0（`qililith/sticky-notes-local-first`），包括电脑侧栏、手机目录与编辑页切换、手机返回、编辑器工具栏和更多菜单、设置页、「数据与同步」。下面这些依赖旧数据层或已决定不做，没有搬过来：本机临时恢复草稿、上传失败条目、云端历史、导入备份、诊断信息复制、更新提示。

## 本地库

每个账号一个 IndexedDB，名字是 `just-note-<userId>`。

- `notes`：列表、摘要、`dirty`、`editSeq`、`serverVersion`、`hasConflict`
- `bodies`：正文 JSON 和纯文本
- `conflicts`：被挤掉的那一版
- `folders`
- `meta`：留给同步游标

编辑停顿约 300 毫秒写入，连续输入最长 1 秒写入一次。页面隐藏、关闭、失焦时立刻写入。写入发现 `editSeq` 已变，先保留库里的那一版，再写入当前内容。

回收站保留 30 天，打开时清理更早的本地条目。
